# Android 历史验收记录

首版记录日期：2026-10-02。环境为 Windows、JDK 17、API 35 Android 模拟器及本地内存 QA 服务。后续手势回归未单独记录日期或提交号；以下结果不能作为当前源码、当前 APK 或线上版本的验收结论。复验步骤见 [Android README](../README.md#本地验收)。

## 已记录的验证

| 范围 | 结果与证据 |
| --- | --- |
| 构建 | Debug 与 R8 压缩的未签名 Release 构建成功；Debug / Release Lint 通过，仍有资源等警告 |
| 会话与导航 | 模拟登录成功，项目、看板和卡片正常加载；系统返回关闭详情，重启应用保留会话 |
| 附件 | 系统“保存到”保存 `android-qa.txt`，adb 读取内容为 `Android QA passed`；重新上传后，服务验证 multipart 内容、会话 Cookie 和 `X-Kanban` 请求头 |
| 无原生顶栏 | 模拟器及无线真机确认无原生顶栏；刷新由 SwipeRefreshLayout 承载 |
| 下拉刷新 | 从页面顶部下拉后 `performance.timeOrigin` 改变，确认重新加载；横向滑动不触发刷新 |
| 拖拽保护 | 长按卡片出现拖拽影子，下移并释放后影子消失，`performance.timeOrigin` 不变 |
| 方向锁定 | 小幅下拉再横移，松手后指示器消失且不重载；超过刷新阈值后再横移，松手正常重载 |
| 网页接口 | 刷新资格由网页判断；交互控件、拖拽区域和嵌套滚动区不参与刷新，缺少接口时禁用下拉刷新 |
| 自动回归 | 首版 4 项 URL 策略测试通过；后续手势回归记录为 29 项 JavaScript 测试、7 项 Android 单测及 Debug 构建 / Lint 通过。这些数字仅对应当时运行 |

## 验证边界

- 当时交付的 Debug 构建已恢复正式服务地址；开发机检查正式首页返回 HTTP 200，未用生产账号执行写操作。
- 停止本地服务后已观察到错误重试界面；最后的超时与页面提交处理改动仅完成构建和 Lint，完整断网恢复流程仍需复验。
- 无线真机禁止 ADB 注入触控，因此自动手势验证在模拟器完成。
- 未记录 Android 8.0 / Android 16 真机或正式发布签名的设备验收。后台系统推送不属于客户端功能。
- 本记录未覆盖近期任务创建表单、通知跳转、列底阴影及侧栏选中样式；网页自动测试不能替代设备验收。
